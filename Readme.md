# Task API

A simple Task Management API built with FastAPI.

## Features

- GET /tasks
- GET /tasks/{id}
- POST /tasks
- PUT /tasks/{id}
- DELETE /tasks/{id}

## Requirements

- Python 3.x
- FastAPI
- Uvicorn

## Installation

```bash
pip install fastapi uvicorn
```

## Run

```bash
uvicorn main:app --reload
```

## Open in Browser

API:

```
http://127.0.0.1:8000
```

Swagger UI:

```
http://127.0.0.1:8000/docs
```
